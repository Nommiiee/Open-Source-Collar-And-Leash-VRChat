# Prefab generation

The editor builder writes `Prefabs/GeneratedCollarAndLeash.prefab` inside the project folder and adds the requested number of instances to the open scene. Open **Tools > Open Source Collar And Leash** and click **Build and Add to Scene**. The first run may create paired UdonSharp program assets; after Unity compiles them, click the button again. The generated prefab depends on the `Runtime` scripts/program assets and `Materials` mesh/material; keep the project folder together.
